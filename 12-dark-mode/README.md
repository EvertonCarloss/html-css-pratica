# Projeto 12 — Dark Mode (Tema Claro/Escuro)

## 📌 Descrição

Este projeto consiste na implementação de um **Dark Mode (modo escuro)** utilizando **HTML, CSS e JavaScript**.

O usuário pode alternar entre tema claro e escuro, e sua preferência é salva no navegador.

---

## 🧠 Conceitos praticados

- Uso de **variáveis CSS (`:root`)**
- Manipulação do DOM com **JavaScript**
- Controle de estado com **classes CSS**
- Persistência de dados com **localStorage**
- Alteração dinâmica de tema

- Interface simples e responsiva
- Mudança dinâmica de cores com variáveis CSS

---

## 📚 Aprendizados

Neste projeto foi possível compreender como utilizar **variáveis CSS para controle global de estilos** e como manter o estado da aplicação utilizando **localStorage**.

Esse padrão é amplamente utilizado em aplicações modernas para melhorar a experiência do usuário.
