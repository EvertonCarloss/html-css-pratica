# Projeto 13 — Formulário com Validação

## 📌 Descrição

Este projeto implementa um **formulário de login com validação** utilizando HTML, CSS e JavaScript.

O sistema valida os dados inseridos pelo usuário e fornece **feedback visual imediato**, melhorando a experiência de uso.

---

## 🧠 Conceitos praticados

- Manipulação do DOM
- Validação de formulários
- Uso de funções reutilizáveis
- Feedback visual com classes CSS
- Regex para validação de email

---

---

## 🎨 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

---

## ⚙️ Funcionalidades

- Validação de campos obrigatórios
- Verificação de email válido
- Validação de senha mínima
- Exibição de mensagens de erro
- Feedback visual (borda vermelha/verde)

---

## 📚 Aprendizados

Neste projeto foi possível entender como funciona a **validação de dados no front-end**, além de aplicar boas práticas de UX ao fornecer retorno visual para o usuário.

Esse tipo de implementação é essencial em sistemas reais.
