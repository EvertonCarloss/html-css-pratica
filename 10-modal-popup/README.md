# Projeto 10 — Modal Interativo

## 📌 Descrição

Este projeto consiste na criação de um **modal (popup) interativo** utilizando **HTML, CSS e JavaScript**.

O modal é um componente muito utilizado em interfaces modernas para exibir conteúdos em destaque, como formulários, alertas ou confirmações.

---

## 🧠 Conceitos praticados

- Manipulação do DOM com **JavaScript**
- Controle de estado com **classes CSS**
- Uso de **overlay (fundo escuro)**
- Posicionamento com **position: fixed**
- Interatividade com **eventListener**
- Fechamento de modal ao clicar fora

## 📚 Aprendizados

Neste projeto foi possível entender como controlar a exibição de elementos na tela através de **JavaScript**, utilizando classes para alterar estados visuais.

Também foi praticado um padrão muito comum em aplicações reais: o uso de **modais interativos**.
