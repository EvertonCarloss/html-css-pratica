# Projeto 10 — Accordion (FAQ Interativo)

## 📌 Descrição

Este projeto consiste na criação de um **Accordion (FAQ interativo)** utilizando **HTML, CSS e JavaScript**.

O accordion é um componente muito utilizado para organizar conteúdos extensos, permitindo que o usuário visualize apenas as informações necessárias ao interagir com a interface.

---

## 🧠 Conceitos praticados

- Manipulação do DOM com **JavaScript**
- Controle de estado com **classes CSS**
- Interatividade com **eventListener**
- Animação com **max-height**
- Estruturação de componentes reutilizáveis
- Lógica para abrir/fechar itens dinamicamente

---

## 🎨 Tecnologias utilizadas

- HTML5

---

## ⚙️ Funcionalidades

- Abrir item ao clicar
- Fechar item ao clicar novamente
- Fechar outros itens ao abrir um novo
- Animação suave na expansão do conteúdo

---

## 📚 Aprendizados

Neste projeto foi possível entender como trabalhar com **múltiplos elementos interativos** na interface, além de reforçar o conceito de **controle de estado em componentes**.

Também foi praticada uma abordagem comum em aplicações reais para exibição de conteúdo dinâmico.
