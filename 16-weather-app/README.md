# Projeto 16 — App de Clima

## 📌 Descrição

Aplicação que consome a API do OpenWeather para buscar informações climáticas de uma cidade.

O usuário digita o nome da cidade e o sistema retorna dados como temperatura, descrição do clima e ícone representativo.

---

## 🧠 Conceitos praticados

- Consumo de API com fetch()
- Async/Await
- Manipulação de dados externos
- Query parameters em requisições
- Renderização dinâmica no DOM
- Tratamento de erros

## ⚙️ Funcionalidades

- Buscar clima por cidade
- Exibir temperatura em Celsius
- Mostrar descrição do clima em português
- Exibir ícone dinâmico
- Feedback de carregamento
- Tratamento de erro para cidade inválida

---

## 📚 Aprendizados

Neste projeto foi possível aprofundar o consumo de APIs externas, entendendo como trabalhar com parâmetros em requisições e lidar com dados mais complexos.
