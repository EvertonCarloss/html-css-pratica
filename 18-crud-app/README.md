# Projeto 18 — CRUD com LocalStorage

## 📌 Descrição

Este projeto implementa um sistema completo de **CRUD (Create, Read, Update, Delete)** para gerenciamento de tarefas.

Os dados são armazenados no navegador utilizando **localStorage**, garantindo persistência mesmo após recarregar a página.

---

## 🧠 Conceitos praticados

- Manipulação de arrays (estado da aplicação)
- CRUD completo (Create, Read, Update, Delete)
- Persistência de dados com localStorage
- Renderização dinâmica no DOM
- Separação de responsabilidades
- Uso de IDs únicos para controle de dados
