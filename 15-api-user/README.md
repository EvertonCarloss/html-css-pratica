# Projeto 15 — Busca de Usuário com API

## 📌 Descrição

Este projeto consome a API pública do GitHub para buscar informações de usuários.

O usuário digita um nome e o sistema retorna dados como foto, nome, bio e link do perfil.

---

## 🧠 Conceitos praticados

- Consumo de API com fetch()
- Async/Await
- Manipulação de dados externos
- Tratamento de erros
- Renderização dinâmica no DOM
