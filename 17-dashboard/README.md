# Projeto 17 — Mini Dashboard

## 📌 Descrição

Este projeto consiste em um **mini dashboard interativo** que integra múltiplas funcionalidades em uma única interface.

O sistema permite:

- Buscar usuários do GitHub
- Consultar clima de uma cidade
- Exibir hora atual em tempo real

---

## 🧠 Conceitos praticados

- Consumo de múltiplas APIs
- Async/Await
- Organização modular de código
- Manipulação do DOM
- Atualização em tempo real (setInterval)
- Layout responsivo com CSS Grid

## ⚙️ Funcionalidades

- Buscar clima por cidade
- Mostrar temperatura atual
- Exibir hora atual em tempo real
- Interface responsiva
