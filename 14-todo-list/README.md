# Projeto 14 — To-Do List (Lista de Tarefas)

## 📌 Descrição

Este projeto consiste em uma **lista de tarefas interativa (To-Do List)** desenvolvida com HTML, CSS e JavaScript.

O usuário pode adicionar, marcar como concluída e remover tarefas dinamicamente.

---

## 🧠 Conceitos praticados

- Manipulação do DOM
- Criação dinâmica de elementos
- Eventos de clique e teclado
- Controle de estado com classes CSS
- Estruturação de lógica em funções

---

```
14-todo-list

├── index.html

```

---

## 🎨 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

---

## ⚙️ Funcionalidades

- Adicionar tarefas
- Adicionar tarefa com botão ou tecla Enter
- Marcar tarefa como concluída
- Remover tarefa
- Interface simples e intuitiva

---

## 📚 Aprendizados

Neste projeto foi possível entender como funciona a **manipulação dinâmica do DOM**, criando elementos em tempo real e respondendo a ações do usuário.

Esse tipo de aplicação representa a base de sistemas interativos modernos.
