# Projeto 07 — Pricing Cards com CSS Grid

## 📌 Descrição

Este projeto consiste na criação de **cards de planos de preço (pricing cards)** utilizando **HTML semântico e CSS Grid**.

A ideia é simular uma seção comum em landing pages de produtos digitais, onde são apresentados diferentes planos de assinatura.

O layout foi desenvolvido com foco em:

- organização visual
- responsividade
- boas práticas de HTML e CSS

---

## 🧠 Conceitos praticados

Durante este projeto foram praticados os seguintes conceitos:

- Estruturação semântica com **HTML**
- Organização de layout com **CSS Grid**
- Criação de **cards reutilizáveis**
- Uso de **variáveis CSS (`:root`)**
- Espaçamento e alinhamento com **gap**
- Estilização de botões e elementos interativos
