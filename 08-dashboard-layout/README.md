# Projeto 08 — Dashboard Layout

## 📌 Descrição

Este projeto consiste na criação de um **layout de dashboard** utilizando **HTML5 semântico e CSS Grid**.

A interface simula a estrutura comum de sistemas administrativos, com:

- **Sidebar de navegação**
- **Header**
- **Cards de estatísticas**

Esse tipo de layout é muito utilizado em **painéis administrativos, plataformas SaaS e sistemas internos**.

---

## 🧠 Conceitos praticados

Durante este projeto foram praticados os seguintes conceitos:

- Estrutura semântica com **HTML5**
- Layout bidimensional com **CSS Grid**
- Organização de interface com **sidebar e área de conteúdo**
- Criação de **cards reutilizáveis**
- Uso de **grid responsivo com `auto-fit` e `minmax()`**
- Espaçamento e alinhamento com **gap**
