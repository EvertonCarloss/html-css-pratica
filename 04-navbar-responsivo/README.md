Projeto 04 – Navbar Responsiva

Este projeto é uma barra de navegação responsiva desenvolvida com HTML5 e CSS3.

🚀 Funcionalidades

Layout moderno

Menu de navegação horizontal

Estrutura semântica com HTML

Responsividade para telas menores usando media queries

🛠 Tecnologias utilizadas

HTML5

CSS3

Flexbox

📚 Aprendizados

Neste projeto pratiquei:

Estrutura semântica com <nav>

Alinhamento com Flexbox

Criação de menu responsivo

Uso de media queries

🎯 Objetivo

Praticar a construção de componentes comuns em interfaces web modernas.

Projeto desenvolvido para prática de HTML e CSS.
