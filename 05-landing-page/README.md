# Projeto 05 – Landing Page Responsiva

Landing page simples desenvolvida com **HTML5 e CSS3**.

## 🚀 Funcionalidades

- Hero section com gradiente
- Botão Call To Action (CTA)
- Seção de features
- Layout responsivo com Flexbox
- Footer simples

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox

## 📚 Aprendizados

Neste projeto pratiquei:

- Estruturação de páginas completas
- Criação de **Hero Section**
- Uso de **gradiente**
- Layout com **Flexbox**
- Organização de seções em uma landing page

---

Projeto desenvolvido para prática de **HTML e CSS**.
