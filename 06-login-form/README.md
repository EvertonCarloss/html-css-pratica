# Projeto 06 — Login Form Moderno

Interface de **login responsiva** desenvolvida utilizando **HTML5 e CSS3**.

O projeto simula uma tela de autenticação comum em sistemas web, com layout centralizado e foco em simplicidade e experiência do usuário.

---

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox

---

## Estrutura do projeto

06-login-form
│
├── index.html
├── style.css
└── README.md

---

## Funcionalidades

- Layout centralizado utilizando **Flexbox**
- Campos de **email e senha**
- Botão de login com **efeito hover**
- Validação básica de formulário com `required`
- Fundo com **gradiente moderno**

---

## Aprendizados

Durante este projeto foram praticados conceitos importantes de desenvolvimento front-end:

- Estruturação de **formulários HTML**
- Uso de **labels e inputs**
- Centralização de layout com **Flexbox**
- Estilização de **inputs e botões**
- Criação de interfaces simples e modernas
