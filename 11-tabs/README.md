# Projeto 11 — Tabs (Abas Interativas)

## 📌 Descrição

Este projeto consiste na criação de um componente de **abas interativas (Tabs)** utilizando **HTML, CSS e JavaScript**.

As tabs permitem alternar entre diferentes conteúdos na mesma área da tela, sendo muito utilizadas em dashboards, páginas de configurações e sistemas web.

---

## 🧠 Conceitos praticados

- Manipulação do DOM com **JavaScript**
- Controle de estado com **classes CSS**
- Uso de atributos **data-\* (data-tab / data-content)**
- Sincronização entre botões e conteúdo
- Alternância de conteúdo com eventos de clique
